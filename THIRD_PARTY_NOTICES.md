# Сторонние материалы

## Chipped

В качестве основы для перевода Chipped использован файл `assets/chipped/lang/ru_ru.json`
из **RTF Extension 2.7.0** (автор проекта — Guardian_50). В проект перенесены только
ключи, присутствующие в Chipped 4.0.2 для Minecraft 1.21.1; после импорта исправлены
термины, грамматика и непереведённые фрагменты.

- Страница проекта: https://www.curseforge.com/minecraft/texture-packs/rtf-extension
- Исходный архив: файл CurseForge №8556933
- Лицензия, указанная на странице проекта: MIT License
